# v737 — Criação de layout fora das "Designadas" do vendedor

- As tarefas de CRIAÇÃO DE LAYOUT antigas (geradas antes da v733 no nome de quem lançou o pedido) passam, uma vez, para o nome do arte finalista (o vendedor original fica guardado em `layout.criadorId`, para a aprovação achar o vendedor).
- O botão Designadas nunca mostra criação de layout: o vendedor só recebe a tarefa de APROVAÇÃO quando o arte finalista envia.
